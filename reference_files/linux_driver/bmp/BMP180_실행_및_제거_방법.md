# BMP180 드라이버 실행 및 제거 방법

폴더: `~/work/practice/linux_fan`  (Jetson Orin Nano, 커널 5.15.x-tegra)

## 0. 처음 한 번만 준비한 것 (이미 완료)

| 항목 | 내용 |
|---|---|
| 커널 헤더 | `/lib/modules/$(uname -r)/build` 가 있어야 빌드 가능 |
| 배선 | SDA = 3번, SCL = 5번, VCC = 1번(3.3V), GND = 6번 핀 (5V에 연결 금지) |
| 센서 확인 | `sudo i2cdetect -y -r 7` 에서 `77` 이 보이면 정상 (`UU` 는 다른 드라이버가 사용 중) |

## 1. 필요한 파일

| 파일 | 역할 |
|---|---|
| `bmp180.c` | 드라이버 본체 (probe, 1초 주기 측정, `bmp180_get_data`, ioctl) |
| `bmp180_calc.h` | 보정 계산 (정수 연산) |
| `fan_common.h` | `struct bmp180_data`, ioctl 번호 (팀 공용) |
| `Makefile` | 빌드 |
| `bmp180_test.c` | 테스트 앱 (선택, 값 확인용) |
| `test_bmp.sh` | 한 번에 올려서 5번 읽고 내리는 테스트 스크립트 (선택) |

## 2. 빌드

```bash
cd ~/work/practice/linux_fan
make
ls bmp180.ko bmp180_test
```

`make clean` 으로 빌드 결과물을 지웁니다. (`sudo` 로 스크립트를 돌렸다면 `sudo make clean`)

## 3. 실행 (운영: 올려 두고 계속 사용)

### 3-1. 모듈 올리기

```bash
sudo insmod bmp180.ko bus=7
```

- `bus=` 는 센서가 보이는 I2C 버스 번호입니다. (3, 5번 핀 = 버스 7)
- LCD 모듈보다 **먼저** 올려야 합니다. LCD가 `bmp180_get_data()` 를 쓰므로 순서가 반대면 `Unknown symbol bmp180_get_data` 오류가 납니다.
- 센서가 없거나 배선이 틀려 probe가 실패하면 `insmod` 도 실패합니다.

### 3-2. 올라갔는지 확인

```bash
lsmod | grep bmp180
dmesg | tail -3                                   # "bmp180: probe ok, major=NNN"
ls -l /sys/bus/i2c/devices/7-0077/driver          # bmp180_fan 으로 연결되면 match → probe 성공
grep bmp180_get_data /proc/kallsyms               # LCD가 쓸 함수가 공개됐는지
```

### 3-3. /dev 노드 만들기 (APP이 ioctl로 읽을 때 필요)

major 번호는 올릴 때마다 달라질 수 있으므로 `/proc/devices` 에서 찾아서 만듭니다.

```bash
MAJ=$(awk '$2=="bmp180"{print $1}' /proc/devices)
sudo mknod /dev/bmp180 c $MAJ 0
sudo chmod 666 /dev/bmp180
ls -l /dev/bmp180
```

이미 노드가 있으면 `sudo rm -f /dev/bmp180` 후 다시 만듭니다.

### 3-3-1. 값 읽는 방법 두 가지

| 읽는 쪽 | 방법 | 값 |
|---|---|---|
| LCD 드라이버 (커널 모듈) | `bmp180_get_data(&d)` 호출 | 1초마다 갱신된 최신 값, 대기 없음, 첫 측정 전이면 `-EAGAIN` |
| APP (유저 프로그램) | `ioctl(fd, BMP180_IOC_READ, &d)` | 호출할 때마다 새로 측정 (약 15ms 걸림) |

값 형식은 `struct bmp180_data` 입니다.

| 필드 | 단위 | 예 |
|---|---|---|
| `temp_x10` | 0.1℃ | 261 → 26.1℃ |
| `pressure_pa` | Pa | 102021 → 1020.21 hPa |

### 3-4. 동작 확인

```bash
./bmp180_test 10        # 1초 간격으로 10번 출력
```

정상 출력 예:

```
temp = 26.1 C (raw x10 = 261), pressure = 102021 Pa (1020.21 hPa)
```

- 온도는 방 온도와 비슷해야 하고(오차 ±1~2℃), 압력은 해수면 근처에서 대략 100000~102000 Pa 입니다.
- 센서를 손으로 잡았다 놓으면 온도가 올라갔다 내려가야 실제 센서 값입니다.
- 압력이 ±10 Pa 정도 흔들리는 것은 정상입니다.
- `bmp180_test` 가 끝나도 모듈은 올라가 있어 계속 1초마다 측정합니다.

## 4. 제거

### 4-1. 모듈 내리기

```bash
# 1) bmp180_get_data() 를 쓰는 다른 모듈(LCD 등)이 올라가 있으면 먼저 내린다
sudo rmmod bmp180
```

- 내리면 1초 주기 측정이 멈추고 `/dev/bmp180` 장치 번호가 해제됩니다.

### 4-2. 노드 지우기

```bash
sudo rm -f /dev/bmp180
```

### 4-3. 내려갔는지 확인

```bash
lsmod | grep bmp180      # 아무것도 안 나오면 제거됨
dmesg | tail -5
```

### 제거가 안 될 때

| 증상 | 원인 | 해결 |
|---|---|---|
| `rmmod: ERROR: Module bmp180 is in use` (다른 모듈이 원인일 때) | LCD 모듈 등 다른 모듈이 `bmp180_get_data()` 를 쓰는 중 | `lsmod` 의 "Used by" 를 보고 그 모듈을 먼저 `rmmod` |
| 같은 오류 (앱 사용 중) | 앱이 `/dev/bmp180` 을 열고 있음 | 앱을 종료한 뒤 다시 시도 |
| 위로도 안 됨 | 위 원인들이 아님 | `dmesg \| tail -20` 확인 |

## 5. 모듈을 수정한 뒤 다시 올릴 때

```bash
sudo rmmod bmp180          # 올라가 있을 때만
make
sudo insmod bmp180.ko bus=7
# 노드는 3-3 으로 다시 만들기
```

## 6. 테스트 스크립트 (선택)

```bash
sudo ./test_bmp.sh 7       # 인자는 I2C 버스 번호 (기본 7)
```

- 빌드 → 모듈 올리기 → 노드 만들기 → 5번 읽기 → 모듈 제거 → 노드 삭제를 한 번에 합니다.
- **혼자 확인할 때만** 쓰세요. 시작할 때 이미 올라가 있는 `bmp180` 을 내렸다가 다시 올리고 끝날 때 제거하므로, LCD나 APP이 쓰는 중에는 실행하지 마세요.

## 7. 참고

- **재부팅하면 모듈이 내려갑니다.** 다시 쓰려면 3-1, 3-3 을 다시 실행해야 합니다.
- 디바이스 트리는 사용하지 않습니다. 장치(Device)는 모듈 안에서 코드로 등록합니다. (`i2c_new_client_device`, 이름 `bmp180_fan`, 주소 0x77) 드라이버는 `i2c_driver` 로 등록되어 이름이 맞으면 `probe` 가 호출됩니다.
- 1초 측정 주기와 해상도 설정은 `bmp180.c` 의 `POLL_MS`, `OSS` 에서 바꿀 수 있습니다.

## 8. 문제가 생겼을 때

| 증상 | 확인 |
|---|---|
| `make` 오류 | 오류 출력 전체를 확인. `led_b*` 파일이 같은 폴더에 있어야 `make` 가 통과함 |
| `insmod` 실패, `dmesg` 에 `i2c bus 7 not found` | `ls /dev/i2c-*` 로 버스 번호 확인 |
| `dmesg` 에 `chip id 0x00` | 센서 응답 없음. 배선, 3.3V 전원, `i2cdetect -y -r 7` 확인 |
| `dmesg` 에 `calib word ... invalid` | 통신 오류. 배선 접촉 불량 확인 |
| `dmesg` 에 `client create failed` | 이미 다른 드라이버(예: 커널 기본 bmp280 계열)가 0x77 사용 중. `lsmod \| grep bmp` |
| `open /dev/bmp180` 실패 | 노드가 없음. 3-3 다시 실행 |
| 온도가 이상하게 높거나 낮음 | 센서 모듈 발열, 배선 확인 |
| 압력 값이 비정상 (예: 0, 음수) | `dmesg` 확인, 모듈을 다시 올려서 재현되는지 확인 |

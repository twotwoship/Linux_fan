# 📌 프로젝트 빌드 및 실행 가이드

이 문서는 모듈 빌드, 커널 모듈 로드 및 애플리케이션 실행 순서를 안내합니다.

---

## 1. 빌드 (Build)

기존 빌드 파일을 정리하고 새로 컴파일을 진행합니다.

```bash
make clean
make
```

---

## 2. 드라이버 모듈 로드 (Module Load)

모듈 로드 시에는 **BMP180**과 **Encoder**를 먼저 준비해야 합니다. 
* *주의: 이미 로드한 모듈은 다시 삽입하지 마세요.*
* *주의: LED 모듈은 기존 로드 상태를 유지하면 됩니다.*

```bash
# 1. BMP180 모듈 로드 (버스 지정)
sudo insmod ./bmp180.ko bus=7

# 2. 엔코더 모듈 로드
sudo insmod ./lt_en.ko

# 3. 팬 모터 모듈 로드
sudo insmod ./fan_motor.ko

# 4. FND 드라이버 모듈 로드
sudo insmod ./fnd_driver.ko
```

# major 번호는 로드 순서/재부팅마다 달라질 수 있으므로 반드시 먼저 확인
grep -E "lt_en|buzz_t" /proc/devices

# 확인한 번호를 <LT_EN_MAJOR>, <BUZZ_MAJOR>에 넣는다 (예: lt_en=488, buzz_t=485)
sudo mknod /dev/lt_en c <LT_EN_MAJOR> 0
sudo mknod /dev/buzz_t c <BUZZ_MAJOR> 0

## 3. 애플리케이션 실행 (Application Run)

모듈 로드가 완료되면 아래 명령어로 메인 애플리케이션을 실행합니다.

```bash
sudo ./fan_app
```

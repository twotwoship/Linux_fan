# 📌 프로젝트 빌드 및 실행 가이드

이 문서는 모듈 빌드, 커널 모듈 로드 및 애플리케이션 실행 순서를 안내합니다.

---

## 1. 빌드 (Build)

이 폴더에는 LED 소스, 공통 헤더와 Makefile이 없습니다. LED 소스, 공통 헤더,
FND/LCD/부저 소스와 Makefile은 `../fan_led_app_bmp100_motor_lt_lcd_buzz/`에 있습니다.
별도 작업 폴더에 통합 폴더의 파일을 먼저 복사한 뒤, 이 폴더의 C 파일을 덮어써서 빌드하세요.
수정된 통합 폴더의 `led_ctl.h`와 `fan_common.h`도 함께 사용해야 합니다.

LED가 꺼져 있던 원인은 PWM duty 불일치입니다. 모터의 65/75/85/95%를
기존 LED는 허용하지 않아 `LED update failed (-22)`가 발생합니다.
수정 후 버튼 순서는 OFF → AUTO → 미풍 → 약풍 → 중풍 → 강풍 → OFF이고,
미풍/약풍/중풍/강풍에서 LED가 각각 1/3/5/7개 켜집니다. AUTO도 같은 매핑을 사용합니다.

보드 없이 매핑 검증: `python3 test_led_mapping.py`.

기존 빌드 파일을 정리하고 새로 컴파일을 진행합니다.

```bash
make clean
make
```

## 2. 드라이버 모듈 로드 (Module Load)

모듈 로드 시에는 **BMP180**과 **Encoder**를 먼저 준비해야 합니다. 
* *주의: 이미 로드한 모듈은 다시 삽입하지 마세요.*
* *주의: 수정한 LED 모듈은 앱을 종료하고 모터 모듈을 내린 뒤 교체해야 합니다.*
  `sudo rmmod fan_motor led_b led_b_dev` 후 아래 순서로 다시 로드하세요.

```bash
# 1. BMP180 모듈 로드 (버스 지정)
sudo insmod ./bmp180.ko bus=7

# 2. 엔코더 모듈 로드
sudo insmod ./lt_en.ko

# 3. LED 장치와 드라이버 로드 (모터보다 먼저)
sudo insmod ./led_b_dev.ko gpios=458,459,401,400,483,482,481 active_low=0
sudo insmod ./led_b.ko

# 4. 팬 모터 모듈 로드
sudo insmod ./fan_motor.ko

# 5. FND 드라이버 모듈 로드
sudo insmod ./fnd_driver.ko
```

## 3. 애플리케이션 실행 (Application Run)

모듈 로드가 완료되면 아래 명령어로 메인 애플리케이션을 실행합니다.

```bash
sudo ./fan_app
```
